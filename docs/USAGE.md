# 项目使用说明

## 基本流程

1. 打开系统页面，选择“创建任务”。
2. 输入项目需求或业务目标。
3. 根据页面提示补充需求信息。
4. 查看生成的产品方案、技术设计与评审结果。
5. 完成审批后，在任务详情加载并保存交付结果。

## 主要页面

- **仪表盘**：查看任务总数、完成状态与最近任务。
- **创建任务**：提交新的需求描述。
- **历史任务**：检索已创建任务并打开详情。
- **任务详情**：查看任务进度、产品方案、技术设计、评审与交付结果。

## 导出内容

完成的任务可导出以下内容：

- 需求澄清结果
- 产品方案
- 技术设计
- 代码骨架建议
- 评审报告
- 完整 JSON 结果

生成内容应由使用者结合实际业务进行复核后再使用。
